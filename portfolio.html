// About

Purpose-built for
engineering teams

Dev-Mate bridges the gap between human intent and working code, with safety and control at every step.

⚙

Dev-Mate is a sophisticated AI software engineering agent built for modern development workflows across Windows, Linux, and macOS. It doesn't just suggest code — it reads your project, plans changes, executes them, and verifies the results.

With multi-provider support (OpenRouter + Google Gemini), Dev-Mate offers flexible AI capabilities for reading, creating, editing, and deleting project files, executing commands and Python code, and running comprehensive tests.

The engineering loop ensures systematic improvement: inspect → plan → edit → execute → diagnose → verify → checkpoint, with human approval for safety-critical operations like deletes, shell commands, and git push.
