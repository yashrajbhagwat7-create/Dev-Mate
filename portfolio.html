// Systematic Loop

The Engineering Cycle

Dev-Mate executes software changes through a disciplined, verification-guided loop instead of speculative unverified code generation.

🔍

1. Inspect & Map

Reads project architecture, searches relevant symbols, and verifies context before attempting any modifications.

✎

2. Targeted Edit

Applies atomic string replacements and creates automatic timestamped rollbacks in .devmate/backups/.

⚙

3. Execute & Verify

Runs tests and builds through guarded execution with real-time return code and stdout/stderr capture.

🤖

4. Diagnose & Fix

If execution encounters an error, the agent isolates root causes directly from output logs and remediates.

🛡

5. Human Checkpoint

Pauses after each engineering iteration, presenting git diffs and status for human-in-the-loop signoff.

🧠

6. Persistent Memory

Maintains structured project knowledge and decision logs across sessions in .devmate/memory.json.

// Architectural Pillars

Engineered for Reliability

Built with robust boundaries that prevent runaway agents, prompt injection exploits, and code destruction.

Multi-Provider

Dual Provider Gateway

Switch between Google Gemini's native function-calling REST endpoints and OpenRouter's vast model catalog on the fly.

Security Sandbox

Strict Path Isolation

Guards against path traversal, Windows special device names, and blocks modification of git hooks and secrets.

Zero Injection

Shell-Safe Python Execution

Executes scripts via direct process invocation (shell=False) under sys.executable, eliminating command injection.

// Security Matrix

Human-in-the-Loop Guarantees

✓ Zero Unvetted Tool Execution

🔒 Guarded Secrets

Environment files (.env, .env.*) and sensitive keys are blocked from model reading or tool tampering.

🗑 Delete & Shell Approval

Destructive commands, file deletions, and shell processes require explicit user approval before execution.

💾 Automatic Backups

Every file edit and write creates an instant timestamped backup in .devmate/backups/ for one-click rollback.

📋 Audit Logging

All tool calls, shell executions, and verification statuses are recorded with sanitization in activity.jsonl.
