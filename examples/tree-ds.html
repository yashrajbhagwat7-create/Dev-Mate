Data Structures

Tree Data Structure

A hierarchical data structure with a root value and subtrees of children, with a parent-child relationship between nodes.

Binary Tree Visualization
Key Concepts
🌳

Root

The topmost node of the tree.

📄

Leaf

A node with no children.

🔗

Edge

Connection between parent and child.

📏

Height

Longest path from root to deepest leaf.

Common Operations

➕ Insertion

Adding a new node to the tree while maintaining the tree properties. In a binary search tree, the new value is compared to the root and recursively placed in the left subtree (if smaller) or right subtree (if larger).

def insert(root, value): if root is None: return Node(value) if value < root.val: root.left = insert(root.left, value) else: root.right = insert(root.right, value) return root

🗑️ Deletion

Removing a node from the tree. There are three cases: leaf node (simply remove), node with one child (replace with child), or node with two children (replace with inorder successor/predecessor).

def delete(root, value): if root is None: return root if value < root.val: root.left = delete(root.left, value) elif value > root.val: root.right = delete(root.right, value) else: # Node with only one child or no child if root.left is None: return root.right elif root.right is None: return root.left # Node with two children: Get inorder successor (smallest in the right subtree) temp = min_value_node(root.right) root.val = temp.val root.right = delete(root.right, temp.val) return root

🔍 Search

Finding a value in a binary search tree by comparing the target with the current node and traversing left (if smaller) or right (if larger) until found or reaching a leaf.

def search(root, value): while root is not None: if value == root.val: return root if value < root.val: root = root.left else: root = root.right return None
